One line: an alien tourist's review of planet Earth after a two-day visit.

The program writes a single line to `entry.txt`:

> Visited Earth. The sunsets are stunning, the food is excellent, but the dominant species spends all day staring at glowing rectangles. 4/5.

An alien's eye view: gorgeous sunsets, great food — and a species that spends all day staring at glowing rectangles. It reads like a real travel review, rating included.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
